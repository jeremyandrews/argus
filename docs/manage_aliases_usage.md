# Alias Management Usage Guide

The `manage_aliases.sh` script provides a simple, streamlined interface for managing entity aliases in Argus.

## Alias Review

Review pending aliases:

```bash
# Review up to 20 pending aliases (default)
./manage_aliases.sh review

# Review up to 10 aliases
./manage_aliases.sh review --limit 10

# Review with a specific admin ID for tracking
./manage_aliases.sh review --limit 5 --admin-id john.doe
```

**Features:**
- ✅ **Immediate start** - begin reviewing aliases right away
- ✅ **Graceful exit** - use 'q' to quit at any time
- ✅ **Progress tracking** - see "Review 3/15" progress indicators
- ✅ **Clean interface** - no confusing batch management

**Interactive Options:**
- `a` - Approve the alias
- `r` - Reject the alias (with reason selection)
- `s` - Skip the alias (leave as pending)
- `q` - Quit review early

## Other Commands

### Add Manual Aliases
```bash
# Add a new alias manually
./manage_aliases.sh add \
  --canonical "Apple Inc." \
  --alias "Apple" \
  --entity-type organization \
  --source admin \
  --confidence 1.0
```

### Test Alias Matching
```bash
# Test if two names are considered aliases
./manage_aliases.sh test \
  --name1 "Apple Inc." \
  --name2 "Apple" \
  --entity-type organization
```

### View System Statistics
```bash
# Get comprehensive alias system statistics
./manage_aliases.sh stats
```

### Migrate Static Aliases
```bash
# One-time migration of static aliases to database
./manage_aliases.sh migrate
```

## Entity Types

Supported entity types:
- `person` - People (e.g., "Tim Cook", "Elon Musk")
- `organization` (or `org`) - Companies, institutions (e.g., "Apple Inc.", "NASA")
- `product` - Products, services (e.g., "iPhone 15", "ChatGPT")
- `location` - Places, regions (e.g., "San Francisco", "California")
- `event` - Events, conferences (e.g., "WWDC 2024", "Super Bowl")

## Tips

1. **Start with stats**: Run `./manage_aliases.sh stats` to see how many pending aliases exist
2. **Small limits**: Start with small limits (5-10) until you're comfortable with the interface
3. **Use descriptive admin IDs**: Use your username or email for better tracking
4. **Regular reviews**: Process aliases regularly to prevent large backlogs
5. **Rejection reasons**: Choose appropriate rejection reasons to improve pattern learning
6. **Use quit option**: Don't hesitate to use 'q' to exit and continue later

## Troubleshooting

**No pending aliases found:**
- Check if aliases are being generated by running `./manage_aliases.sh stats`
- Verify entity extraction is working properly in your news processing pipeline

**Database connection errors:**
- Ensure `DATABASE_PATH` environment variable is set correctly
- Verify the database file exists and is writable

**Permission errors:**
- Ensure the script is executable: `chmod +x manage_aliases.sh`
- Check database file permissions
